### **Morse Code Translator**

A simple GUI-based Morse Code Translator built using Python and Tkinter. It allows users to convert English text to Morse code and vice versa.

**Features**
------------

✅ Convert English text to Morse code  
✅ Convert Morse code to English text  
✅ User-friendly GUI built with Tkinter  
✅ Copy-paste support for easy translation

**Installation**
----------------

1.  Clone the repository:
    
    ```bash
    git clone https://github.com/yourusername/morsecode_translator.git
    cd morsecode_translator
    ```
    
2.  Install dependencies:
    
    ```bash
    pip install -r requirements.txt
    ```
    
3.  Run the script:
    
    ```bash
    python morse_translator.py
    ```
    

**Usage**
---------

*   Type English text or Morse code in the input box.
*   Click the **Translate** button to convert it.
*   Copy the result and use it as needed.
